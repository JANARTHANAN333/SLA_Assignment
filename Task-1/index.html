1. Semantic Tags

What are Semantic Tags?

Semantic tags describe the meaning of content. Examples are header, nav, main, section, article, aside and footer.

Semantic vs Non-Semantic

Semantic: header, article, section

Non-semantic: div, span

Side Note

Semantic tags improve accessibility and help search engines understand webpage content.
